# PolarLabs QR Studio v1.1.0

**Nuove versioni gratuite per Windows e Linux.**

Questa release introduce pacchetti compilati nativamente per quattro piattaforme:

- **Windows x64** — Windows 10/11 con CPU Intel o AMD a 64 bit.
- **Windows ARM64** — Windows 11 ARM, inclusi Microsoft Surface ARM.
- **Linux x64** — distribuzioni con desktop grafico e architettura x86_64.
- **Linux ARM64** — distribuzioni con desktop grafico e architettura aarch64.

Le versioni Linux vengono compilate su Ubuntu 22.04 per migliorare la compatibilità con sistemi basati su glibc. Per usarle: estrarre il file .tar.gz e avviare ./PolarLabs-QR-Studio; potrebbe essere necessario assegnare il permesso di esecuzione con chmod +x.

Le funzionalità restano le stesse: generazione mosaici QR Pixel Art con loghi PNG/SVG, modalità Mosaico fedele, verifica della scansione ed esportazione in PNG/SVG.

**Sicurezza:** le applicazioni non sono firmate digitalmente. Non disattivare SmartScreen o i controlli di sicurezza. È sempre disponibile il codice sorgente MIT.

Tutti e quattro i pacchetti sono sottoposti a test automatici e verifica dei formati archivio prima della pubblicazione.
